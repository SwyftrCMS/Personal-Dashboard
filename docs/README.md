# Personal Health & Fitness App

Single-user, mobile-first, monochrome application. Reduce daily decisions and track adherence to an existing plan. No AI coaching, social features, subscriptions or external food database.

## Build instructions for Google AI

Read all six Markdown files before implementation. Use HEALTH_FITNESS_PLAN.md as the initial seed, APP_SPEC.md for behaviour, UI_UX.md for presentation, DATA_MODEL.md for persistence and BUILD_PLAN.md for acceptance criteria. Implement a working application, not a static mockup. Prefer React, TypeScript and IndexedDB; use a PWA if supported. Do not require authentication for local-only operation. Do not send personal health data to external services. Use no fabricated historical data. Seed plan templates only. Ask for clarification only if a blocking conflict exists. Editable settings supersede seed values after first launch; never reseed over user changes.

## Success criteria

Open the app, see today's plan, log actual actions in one or two taps, review trends and edit future plans. Target less than two minutes of daily administration excluding journaling. Keep the original plan available for reference. Use Australia/Sydney timezone, metric units and Australian date formatting.
